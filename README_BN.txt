Rahat Sure Shot — Android Studio project

এটি একটি শিক্ষামূলক price-analysis app। এটি লাইভ Quotex data নেয় না, Quotex-এ লগইন করে না এবং কোনো trade place করে না। এটি manually দেওয়া closing price থেকে RSI ও EMA trend হিসাব করে।

APK বানানোর ধাপ:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP extract করুন।
3. Android Studio-তে এই folder Open করুন।
4. Gradle sync শেষ হতে দিন।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
6. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk ফোল্ডারে পাওয়া যাবে।

সতর্কতা:
- এটি লাভ নিশ্চিত করে না এবং CALL/PUT signal generator নয়।
- Binary options অত্যন্ত ঝুঁকিপূর্ণ; বাস্তব টাকা ব্যবহার করার আগে demo-তে পরীক্ষা করুন।
- অ্যাপটি কোনো ব্যক্তিগত তথ্য বা account credentials চায় না।
